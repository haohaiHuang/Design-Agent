## 六轮总结论（回答"流程是否最优"）

1. **机械门有效且可扩展**：4→7 类检查；error 5→0；每加一次都由真实失败驱动（HC-5 来自过期取证、HC-6 来自幽灵令牌、HC-7 来自验收自相矛盾、HC-1 扩展来自 HTML 断链）。
2. **未加机械覆盖的类仍需人工**：现值真伪、计数、取整、跨节矛盾、类名→规格完整性。
3. **成本没有改善**：100–162 步 / 198–265k 上下文 / 89–167k 输出；**同素材同提示词波动 ±60%**，单轮不可比。
4. **成本中心**：渲染/截图/PDF 管线占 bash 的 59%；输出中推理 52% + 工具参数 46%。
5. **被证伪的两个判断**（留档防再犯）：① "上下文 95% 触顶"（实际窗口 1M）；② "批次化让成本 +38%"（实为波动）。
