## 关键结论：机械门的覆盖边界被量出来了

**HC error 0，而第三方判「不能开工」** —— 说明 HC 只覆盖「跨文件数值漂移 / 路径可达 / 证据时间」，
**不覆盖**：
- 选择器/类名**在原项目里是否存在**（第 17 项落空 → A-1/A-6 双 ❌）
- **范围自洽**（打补丁 vs 重建）
- **命令可跑性**（`grep -r` / BSD 不支持 `-P`）——HC-4 只查了"是否标归属"
- 非数值字段的措辞冲突（字重档数、线宽）
