# 焦点与平衡（01–06）

## 01 中轴对称 Axial Symmetry
- 结构：所有主要元素围绕中轴组织，左右视觉重量接近；视线沿中轴下行（上标题 → 中主视觉 → 下信息）。
- 适合：品牌发布 / 展览 / 奢侈品 / 典礼 / 单一主角。
- B 配方：[标签] 中轴 镜像平衡 中央焦点 庄重 axial symmetry centered composition mirrored balance ｜ [结构句] 中轴构图，标题在上、主视觉居中、信息在下，严格对称，庄重仪式感。
- A 约束：单列居中 grid（justify-items/align-items: center）；左右边距镜像相等；主视觉占中轴一列。
- 避坑：禁逐个元素机械镜像（信息多时易僵硬 → 改 20 多栏网格）。

## 02 非对称平衡 Asymmetrical Balance
- 结构：左右形状不同，靠大小/明度/密度/距离交换视觉重量，形成有张力的稳定。
- 适合：文化海报 / 设计展 / 时尚 / 科技 / 当代品牌。
- B 配方：[标签] 非对称 视觉配重 偏置焦点 动态稳定 asymmetrical balance visual counterweight offset focal point ｜ [结构句] 大形体在左、高对比信息块在右完成配重，非对称但有平衡。
- A 约束：grid 两栏非对称比例（如 60/40 或 70/30）；重侧大尺寸、轻侧用高对比小元素；偏置不居中。
- 避坑：偏左≠平衡——另一侧必须有足够对比或密度回应。

## 03 三分法焦点 Rule of Thirds
- 结构：画面横竖各分三份，焦点放分割线或交点附近，稳定而自然偏移。
- 适合：摄影主导海报 / 人物 / 产品 / 活动 / 网页 Hero。
- B 配方：[标签] 三分法 交点焦点 偏心留白 rule of thirds thirds intersection off-center subject ｜ [结构句] 主视觉在三分交点处，偏心留白，标题沿分割线排布。
- A 约束：主视觉定位在横向 1/3 或 2/3 处（grid 跨度或绝对定位交点）；标题与主视觉共享一条分割线。
- 避坑：禁为卡交点牺牲主体朝向 / 文字空间 / 裁切。
- 起步推荐（原文）：只试一种就选它，产品/人像/活动封面/网页首屏都稳。

## 04 黄金螺旋 Golden Spiral
- 结构：逐级缩小矩形与弧线组织焦点和节奏；作比例草图用，非必须服从的定律。
- 适合：艺术 / 自然 / 电影 / 叙事型产品 / 概念海报。
- B 配方：[标签] 黄金螺旋 比例递进 收束焦点 golden spiral Fibonacci layout progressive scale ｜ [结构句] 元素按逐级缩小比例递进，视线沿弧线收束到内圈焦点。
- A 约束：多级卡片/元素 scale 递进（如 1/1.618 级差）；焦点收束在最小单元。
- 避坑：禁把螺旋线直接贴成品；内容层级仍优先于比例。

## 05 大留白单点 Isolated Focal Point
- 结构：大面积主动留白隔离一个小而明确的焦点，稀疏本身成为语气。
- 适合：高端品牌 / 艺术展 / 诗歌 / 香氛 / 安静的产品传播。
- B 配方：[标签] 大留白 孤立焦点 低密度 克制 macro white space isolated focal point minimal composition ｜ [结构句] 大面积留白，单一焦点偏置，少量文字，低密度。
- A 约束：全页元素分组 ≤3；主内容区留白占比 ≥ 区面积 2/3；焦点对比 ≥2 维（尺寸+明度）。
- 避坑：留白≠把内容缩小——焦点需足够对比/质感/语义支撑。

## 06 边缘锚定 Edge-Anchored
- 结构：主体推向画面边缘并允许裁切，屏外延伸感制造尺度与张力。
- 适合：时尚 / 人像 / 产品特写 / 社媒封面 / 强态度传播。
- B 配方：[标签] 边缘锚定 越界裁切 屏外延伸 edge-anchored cropped subject off-canvas continuation ｜ [结构句] 主体贴边被裁切，向画外延伸，文字在剩余安全区。
- A 约束：主视觉 overflow:hidden + 负 margin/偏移贴边；裁切线避开关键结构；预留安全区。
- 避坑：禁误裁脸 / 关节 / 文字 / 产品关键结构；必须留安全区。

# 几何骨架（07–10）

## 07 三角 / 金字塔 Triangular Hierarchy
- 结构：元素构成稳定三角，顶点强调、底边承重，天然三层层级。
- 适合：人物群像 / 电影 / 论坛 / 权威主题 / 层级明确的发布。
- B 配方：[标签] 三角构图 金字塔层级 稳定底座 triangular composition pyramid hierarchy stable base ｜ [结构句] 顶点焦点、两侧下行、底边信息，三层稳定结构。
- A 约束：三列/三层递减布局（顶 1 列 → 底 2 列）；顶点元素最大或对比最强。
- 避坑：三角外不能出现更强焦点，否则骨架塌。

## 08 倒三角悬置 Inverted Triangle
- 结构：上宽下窄，重量悬于上方，制造不稳定 / 压迫 / 速度 / 危险感。
- 适合：先锋艺术 / 音乐 / 悬疑 / 警示 / 反传统文化。
- B 配方：[标签] 倒三角 悬置重心 漏斗收束 inverted triangle unstable balance downward convergence ｜ [结构句] 上方宽区收束到下方尖点，视线被压向结论。
- A 约束：顶部宽栏 + 底部收窄单点；重心偏上（上大下小、上密下疏）。
- 避坑：不适合强调可靠与舒适的主题；底部文字防被尖点挤压。

## 09 同心环绕 Concentric
- 结构：多个同中心的环/框/形状反复包围焦点，强调聚焦、回声、层层深入。
- 适合：音乐 / 科技 / 声波 / 社区 / 周年 / 抽象主题。
- B 配方：[标签] 同心 环绕焦点 层层收束 concentric composition nested rings central convergence ｜ [结构句] 外圈先建场域，环线层层收束到中心焦点。
- A 约束：嵌套 border/ring 层（多层同心圆/圆角框）；中心焦点；环与文字错开。
- 避坑：中心文字必须与环线错开；环太多产生噪声/眩晕。

## 10 框中框 Frame within Frame
- 结构：边框/窗口/嵌套容器反复限定观看范围，形成展陈感与纵深。
- 适合：艺术展 / 建筑 / 档案 / 摄影 / 复古印刷 / 画册封面。
- B 配方：[标签] 框中框 嵌套边界 窗口焦点 frame within frame nested borders contained focal area ｜ [结构句] 外框限定范围，内框进入主体，框外放注释。
- A 约束：嵌套容器（外层 border + 内层内容区）；焦点在内框；框线视觉弱于文字层级。
- 避坑：框线层级不能与文字层级竞争；内框太小像缩略图。

# 动势路径（11–14）

## 11 对角线动势 Diagonal Tension
- 结构：强斜轴贯穿画面，打破水平稳定，快速建立速度 / 冲突 / 方向。
- 适合：体育 / 音乐 / 促销 / 科技 / 行动号召 / 青年文化。
- B 配方：[标签] 对角线 斜轴 速度 切割 diagonal composition dynamic axis directional tension ｜ [结构句] 元素沿斜轴从一角穿向对角，信息依附或反向切断斜轴。
- A 约束：主视觉沿对角线排布（rotate 或斜切 grid）；信息块依附斜轴放置。
- 避坑：正文禁全部倾斜；斜线必须指向有效信息而非画外。

## 12 放射爆发 Radial Burst
- 结构：线条/形状/人物从共同中心向外辐射，能量爆发与集中传播。
- 适合：音乐节 / 促销 / 庆典 / 运动 / 宣言 / 强情绪活动。
- B 配方：[标签] 放射 爆发中心 向外扩散 radial burst radiating lines explosive focal point ｜ [结构句] 射线从唯一中心向外辐射，中心文字收束视线。
- A 约束：中心焦点 + conic-gradient/重复线条向外辐射；放射中心唯一。
- 避坑：放射中心必须唯一；细密射线干扰小字号。

## 13 Z 型路径 Z-Path
- 结构：左上→右上→左下→右下四锚点折线，适合少量信息顺序阅读。
- 适合：活动 / 产品页首屏 / 课程 / 发布会 / 社媒广告。
- B 配方：[标签] Z 型路径 四角锚点 顺序阅读 Z-pattern layout corner anchors sequential scan ｜ [结构句] 左上标题、右上主视觉、左下说明、右下 CTA。
- A 约束：四角锚点 grid；阅读顺序 = DOM 顺序 = 左上→右上→左下→右下。
- 避坑：Z 是编排脚手架，不是所有观众的固定眼动规律。

## 14 S 型曲线 S-Curve
- 结构：柔和反向曲线连接多个焦点，产生流动 / 优雅 / 渐进叙事。
- 适合：美妆 / 时尚 / 舞蹈 / 自然 / 饮品 / 优雅叙事。
- B 配方：[标签] S 曲线 蛇形路径 柔性动势 S-curve composition serpentine flow graceful movement ｜ [结构句] 视线从上方一侧切入，沿 S 曲线越过中央到达下方另一侧，每弯一个信息节点。
- A 约束：多焦点错位排布（交替左右/上下，形成 S 轨迹）；每弯一个节点。
- 避坑：禁曲线成为无关装饰——每次转弯应有信息节点。

# 分割与条带（15–18）

## 15 L 型锚定 L-Shaped Anchor
- 结构：一条竖向 + 一条横向信息带在角落相交，像支架托住主视觉。
- 适合：建筑 / 展览 / 目录 / 理性品牌 / 空间与工业主题。
- B 配方：[标签] L 型 角落锚点 边栏 L-shaped layout corner anchor edge rails ｜ [结构句] 竖边信息带 + 横边信息带在角落相交，主视觉被框在内部。
- A 约束：左边/底边双信息带（grid 行列）+ 主内容区；两臂有明显长短关系。
- 避坑：L 两臂需明显长短关系；四边都封闭会变成框中框。

## 16 左右分屏 Vertical Split
- 结构：画面垂直分成两个对等或主次区域，用于对比 / 问答 / 前后 / 双主题。
- 适合：对比型产品 / 双人 / 前后变化 / 观点碰撞 / 联名。
- B 配方：[标签] 左右分屏 双主题 并置对比 vertical split dual-panel composition juxtaposition ｜ [结构句] 左右两区域并置，强对比侧先读，跨中缝读关系。
- A 约束：两栏 grid；主次比例用 62/38 或 70/30（禁 50/50 缺主次）；中缝留间隙。
- 避坑：两侧必须有明确关系；50/50 分割缺乏主次。

# 网格系统（19–24）

## 17 上下分屏 Horizontal Split
- 结构：水平分界把图像与文字或两个场景叠放，形成先后和上下文关系。
- 适合：电影 / 旅行 / 讲座 / 产品说明 / 数据+图像。
- B 配方：[标签] 上下分屏 地平线分割 图文两层 horizontal split stacked panels image-text division ｜ [结构句] 上方主视觉，下方解释文字，主次比例明确。
- A 约束：上图像下文字两行 grid；比例 62/38 或 70/30；分界避开主体脸 / 文字中线。
- 避坑：分界禁卡在主体脸部或文字中线；上下要体现主次。

## 18 水平带状 Horizontal Bands
- 结构：多个横向色带/内容带分层，产生节拍、章节感与横向速度。
- 适合：音乐 / 交通 / 体育 / 时间表 / 系列活动 / 信息密集海报。
- B 配方：[标签] 水平色带 分层条带 章节节奏 horizontal bands striped layout stacked information bars ｜ [结构句] 多条横向带分层，最强色带先读，按带宽/颜色/编号逐层移动。
- A 约束：多行 grid 色带；以带宽/颜色区分主次（一条最强）；禁等宽同等抢眼。
- 避坑：每条带不能同等抢眼；避免段落挤成过窄行长。

## 19 单栏手稿网格 Single-Column Grid
- 结构：所有信息落在一个连续主栏，靠边距、段距与字号建立阅读秩序。
- 适合：宣言 / 文学 / 学术 / 演讲 / 极简产品说明。
- B 配方：[标签] 单栏网格 线性阅读 大边距 single-column grid manuscript grid linear reading ｜ [结构句] 单栏连续文本，大边距，线性阅读。
- A 约束：单列 + 大左右边距；行长（measure）控制在 45–75 字符；字号/段距分层。
- 避坑：海报不是论文页——行长、段落数、字号必须适合远读。

## 20 多栏编辑网格 Multi-Column Grid
- 结构：多条纵向栏提供灵活跨度，图像与文本可占一栏或跨栏，适合复杂层级。
- 适合：编辑海报 / 会议 / 课程表 / 展览目录 / 数据与说明。
- B 配方：[标签] 多栏网格 跨栏 编辑布局 multi-column grid column span editorial layout ｜ [结构句] 多栏网格，大跨栏元素先定级，再按栏线读细分信息。
- A 约束：4–12 栏 grid + 重复栏宽/沟槽；大元素跨栏、小元素占栏；跨栏规则统一。
- 避坑：禁所有元素随机跨度——需要重复的栏宽和沟槽。

## 21 模块网格 Modular Grid（下册起步推荐）
- 结构：纵栏×横行交叉成可复用模块，图像/文字/编号按模块组合，适合高密度系统化信息。
- 适合：瑞士风格 / 信息设计 / 活动日程 / 展览 / 系列视觉。
- B 配方：[标签] 模块网格 矩阵 跨模块 modular grid matrix layout grid modules ｜ [结构句] 先搭 4×6 模块网格，80% 元素归位，一个标题跨出去。
- A 约束：grid 矩阵（如 4×6 模块）；80% 元素落模块内 + 1 个破格跨模块标题；模块间距统一。
- 避坑：网格是底层关系，不必把每条线都画出来。
- 起步建议（原文）：承接标题/图片/数据/说明，最易翻译成 HTML。

## 22 瑞士非对称网格 Swiss Grid
- 结构：严格网格、左对齐无衬线字、非对称留白、客观摄影——国际主义理性语气。
- 适合：设计展 / 建筑 / 音乐会 / 文化机构 / 理性科技品牌。
- B 配方：[标签] 瑞士风格 左齐右不齐 客观排印 Swiss style International Typographic Style flush left ragged right ｜ [结构句] 严格模块网格，大字号无衬线左对齐标题，非对称留白，理性排印。
- A 约束：严格 grid + text-align:left（左齐右不齐）；无衬线 display 字；非对称留白。
- 避坑：加红圆和 Helvetica 不等于瑞士风格——关键是结构与层级。

## 23 层级卡片网格 Bento / Hierarchical Grid
- 结构：不同尺寸矩形区块共享统一间距与圆角，卡片面积表达信息优先级。
- 适合：科技 / 产品功能 / 数据 / 服务组合 / HTML 落地页。
- B 配方：[标签] Bento 网格 层级卡片 不等模块 bento grid hierarchical cards variable-span grid ｜ [结构句] 不等尺寸卡片共享间距圆角，最大卡片先读。
- A 约束：grid-template 不等跨度；卡片共享同一间距档位与圆角；面积=优先级；同层语义一致。
- 避坑：不是随意拼方块——同层卡片需要一致语义和间距。

## 24 棋盘交替 Checkerboard
- 结构：图像与文字在规则矩阵中交替，利用反转、重复和对应形成节奏。
- 适合：系列产品 / 作品集 / 活动阵容 / 对照概念 / 时尚。
- B 配方：[标签] 棋盘 图文交替 反转节奏 checkerboard layout alternating tiles image-text rhythm ｜ [结构句] 图文在矩阵中交替反转，整体先于局部被感知，留一个破格焦点。
- A 约束：偶数栏 grid，行内图/文交替（nth-child 反转）；需要一个破格焦点元素。
- 避坑：矩阵过细像社媒九宫格——需要一个破格焦点。

# 图文关系（25–28）

## 25 满版主视觉 Full-Bleed Hero
- 结构：单张图像铺满画布，文字叠加或放入局部安全区，情绪与沉浸优先。
- 适合：电影 / 旅行 / 时尚 / 摄影 / 产品氛围 / 人物。
- B 配方：[标签] 满版图像 沉浸主视觉 文字叠图 full-bleed image hero image type overlay ｜ [结构句] 图像铺满全画布，高对比标题叠加在安全区。
- A 约束：图 position:absolute 铺满 + 文字叠安全区；文字下方加 scrim（渐变遮罩保证对比度）。
- 避坑：文字禁压复杂纹理；裁切焦点需跨尺寸管理（响应式）。

## 26 大字主导 Typographic Dominant
- 结构：把标题本身当主视觉，靠尺度、字重、字距、断行、裁切建立图像感。
- 适合：观点 / 宣言 / 音乐 / 促销 / 社会议题 / 无图素材。
- B 配方：[标签] 大字海报 字体主视觉 超尺度标题 big type poster typographic dominant oversized headline ｜ [结构句] 巨型标题关键词做主视觉，细节信息藏在字形缝隙或边缘。
- A 约束：display 字号大 3–4 级（标题/正文 ≥3x）；字重两档内；断行保留语义；clamp() 控跨尺寸。
- 避坑：大字≠全部加粗；断行必须保留语义与辨识度。

## 27 图上叠字 Type over Image
- 结构：文字与图像共享同一空间，通过遮挡、穿插、对比建立一体化主视觉。
- 适合：时尚 / 人像 / 杂志 / 电影 / 音乐 / 文化活动。
- B 配方：[标签] 图上叠字 图文穿插 前后层级 type over image interleaved typography foreground-background layering ｜ [结构句] 标题与图像同空间，明确字在前/在后/穿插，前后层级可辨。
- A 约束：标题与图同容器（position 叠层）；明确前后层；文字落在图上低纹理区或加 scrim。
- 避坑：必须明确字在前、字在后或字穿插；半透明一盖了之通常发灰。

## 28 双联 / 三联 Diptych / Triptych
- 结构：一个主题拆成两个/三个连续画幅，用重复与变化表现时间、对比、多视角。
- 适合：叙事 / 前后 / 系列产品 / 人物组 / 电影 / 摄影展。
- B 配方：[标签] 双联 三联 连续画幅 diptych triptych sequential panels ｜ [结构句] 2–3 个连续画幅，共享同一变量，在相似结构中比较变化。
- A 约束：等分 grid（2/3 栏）+ 每格共享同一构图变量；格间距统一。
- 避坑：每格要有共同变量——三张无关图并排不构成三联。

# 破格与节奏（29–32）

## 29 拼贴层叠 Overlapping Collage
- 结构：图像/纸片/纹理/文字以遮挡与旋转叠加，制造手工、记忆与亚文化语气。
- 适合：音乐 / 青年文化 / 杂志 / 艺术 / 复古 / 手工品牌。
- B 配方：[标签] 拼贴 层叠 撕纸 遮挡 overlapping collage torn paper layered ephemera ｜ [结构句] 多层元素遮挡旋转叠加，最高对比层先进入，靠层级而非网格推进。
- A 约束：多元素绝对定位 + 遮挡 + 受控旋转；统一材质/色彩/叙事线索；层级 z-index 明确。
- 避坑：随机旋转不是拼贴——需要统一的材质、色彩或叙事线索。

## 30 破格网格 Broken Grid
- 结构：先建立可感知的网格，再让少数关键元素跨线、错位或越界，以破坏制造强调。
- 适合：先锋文化 / 设计展 / 科技 / 实验编辑 / 作品集。
- B 配方：[标签] 破格网格 跨线 错位 控制性破坏 broken grid intentional misalignment grid disruption ｜ [结构句] 规则网格建立预期，1 个破格元素越界成为焦点。
- A 约束：先完整建网格 + 仅 1 个元素跨线/错位；其余全部归位。
- 避坑：没有底层网格就没有"破格"；每个元素都错位只会混乱。

## 31 重复节奏 Repetition & Pattern
- 结构：重复同一形状/图像/文字建立节拍，再以一个差异项形成焦点。
- 适合：系列产品 / 群体 / 音乐 / 运动 / 数据 / 概念传播。
- B 配方：[标签] 重复 模式 节奏 破例焦点 repetition pattern one anomaly rhythmic grid ｜ [结构句] 规则重复建立模式，一个破例元素成为焦点。
- A 约束：重复单元 grid/pattern + 仅 1 个差异项（尺寸/颜色/内容）；差异必须服务主题。
- 避坑：重复项过多且无变化会成为背景噪声；差异必须服务主题。

## 32 密集全铺 Dense All-Over
- 结构：高密度元素覆盖整个画面，靠整体纹理、局部对比与多尺度层级制造最大主义冲击。
- 适合：节日 / 地下音乐 / 潮流 / 复古广告 / 阵容很多的活动。
- B 配方：[标签] 密集全铺 最大主义 多尺度 纹理化信息 dense all-over maximalist poster horror vacui multi-scale hierarchy ｜ [结构句] 高密度覆盖，最大尺度或最强色差元素提供局部入口。
- A 约束：高密度网格/纹理 + 至少 1 个清晰入口（标题/日期/CTA）；多尺度字号层级。
- 避坑：密集≠没有层级——标题、日期与 CTA 仍需至少一个清晰入口。

# 验收清单（原文 6+8 项合并去重，全词条通用）

1. 入口存在吗？——缩成手机信息流大小，第一眼还能找到标题或主视觉。
2. 第一眼焦点清楚吗？——标题和图片同样抢眼时，弱化一个。
3. 三层信息能分出来吗？——标题/主视觉/辅助信息需明显尺度差。
4. 主次比例清楚吗？——60/40、70/30 或跨栏数量应能解释视觉重量。
5. 共同边线稳定吗？——标题/图片边缘/日期/说明至少共享 1–2 条对齐线。
6. 沟槽一致吗？——同层级间距需重复，不能每个模块一个距离。
7. 留白在帮助阅读吗？——空间应隔离内容或强调焦点，不是"没有东西"。
8. 破格数量受控吗？——一般保留一个主破格元素就够了。
9. 图文层级明确吗？——图上叠字时能判断字在前/在后/穿插。
10. 裁切焦点安全吗？——人脸、产品标志、标题关键笔画、CTA 不能被切。
11. HTML 能响应吗？——改变容器宽度后构图关系仍成立，不能只在一张截图好看。

## 使用口诀（原文）
- 少写一个模糊的风格词，多写一句画面路径：观众从哪里开始看，沿什么方向移动，最后停在哪里。
- 生成后先改结构参数，别急着继续堆风格词。
